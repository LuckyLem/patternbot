# Lern-Labor

Ergebnisse, Logbücher und Vorab-Dateien des Lern-Labors. Der Code liegt nicht im Repo. Der Fahrplan liegt auf main
(FAHRPLAN.md).

| Datei | Inhalt |
|---|---|
| `status.json` | Daten für die Lern-Labor-Seite (Stand, Lernzeit, Etappen, Logbuch, Backtest-Stand) |
| `logbuch.md` | Zugriffstests, Abschneide-Tests, Vorab-Dateien, Prüftopf-Öffnungen; wird nur ergänzt |
| `prueftopf-logbuch.md` | jede Öffnung des Prüftopfs (höchstens 3) |
| `kandidaten.md` | Ideen aus Büchern als prüfbare Regeln, in eigenen Worten |
| `datenplan.md` | welche Daten, wofür, wie groß |
| `entwuerfe/` | Entwürfe: Lernzeit-Wächter und Einrichtung auf dem Pi, Telegram-Texte |
| `vorab/` | Vorab-Dateien, je Etappe und Version (folgen) |
