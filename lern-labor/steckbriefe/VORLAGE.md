# Steckbrief-Vorlage

Jedes Muster bekommt einen Steckbrief. **Ein Steckbrief ist eine feste Regel.** Wird etwas daran geändert, entsteht ein
neues Muster mit neuer Nummer (z. B. M010 → M011). Der alte Steckbrief bleibt unverändert stehen.

**Herkunft neuer Ideen:**
- Der Inhaber schickt ein Bild oder eine Idee an Claude im Chat.
- Daraus wird ein Steckbrief, der in `kandidaten.md` eingetragen wird.
- Getestet wird einmal pro Woche als Paket im Lerntopf.
- Regeln werden nie nach Ergebnissen geändert.

**Zeitebene:** Sie gibt das Muster vor.
- Muster auf Tageskerzen werden über mehrere Tage gehalten, auch über Nacht.
- Sie laufen nur in Simulation und Schatten, ins Paper nur mit OK des Inhabers.

**Stufen:**

| Stufe | Bedeutung |
|---|---|
| 0 | Idee: Steckbrief liegt vor |
| 1 | Lerntopf bestanden: jedes Lernjahr positiv, über der Zufallslatte, hält dem Kostenstress stand |
| 2 | Prüfung bestanden: im Prüftopf, bei einer der 3 Öffnungen |
| 3 | Schatten bestanden: 200 Trades, 3 Monate, alle 5 Kriterien |
| 4 | Paper, nur mit OK des Inhabers |

---

## Mxxx · Name

| Feld | Inhalt |
|---|---|
| Nummer und Fassung | Mxxx, angelegt am …, Stufe … |
| Name, Quelle | Name des Musters; woher die Regel stammt (Buch und Kapitel, Live-Code, Idee des Inhabers) |
| Zeitebene und Zoom | z. B. 15-Min-Kerzen IEX, Fenster von … Kerzen, Zoomstufen … |
| Vortrend | welcher Trend vorher da sein muss und wie er gemessen wird |
| Linienregeln | welche Punkte (Wendepunkte welcher Größe); Dochte oder Körper; Mindestberührungen je Linie; Toleranz |
| Gültig nur, wenn … | alle Bedingungen, die das Muster erfüllen muss, bevor es zählt |
| Auslöser | was genau den Einstieg auslöst (z. B. Schlusskurs der 15-Min-Kerze über der Kante) |
| Stop | wo und woraus berechnet |
| Ziel | wo und woraus berechnet |
| Ungültig, wenn … | was das Muster vor dem Auslöser verwirft |
| Haltedauer | bis wann der Trade läuft (Zeit-Stopp, Tagesende, über Nacht nur in Simulation und Schatten) |
| Bewertungsmerkmale | was die Qualität beschreibt (Berührungen, Passgüte, Volumen, Dochte, Abprall, Vortrend …) |
| Darstellung im Bild | welche Linien, Punkte und Flächen das Bild zeigt |
| Selbstkontrolle | welche Prüfungen vor jeder Bewertung laufen (Mindestberührungen, Ausreißer-Docht mit SIP, Signalkerze) |
